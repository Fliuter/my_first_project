# Практическая работа №10 — JavaScript: работа с функциями

## Состав проекта
- `index.html` — страница проекта и запуска тестов.
- `functions.js` — реализация функций из задания.
- `tests.js` — автоматические проверки, включая граничные случаи.
- `style.css` — оформление страницы.
- `answers_pr10.txt` — ответы на 10 вопросов для самоконтроля.

## Запуск
1. Распакуйте папку `js_functions`.
2. Откройте `index.html` в браузере.
3. Откройте инструменты разработчика клавишей F12, если нужно посмотреть консоль.
4. Нажмите «Запустить тесты».

## Примечание
Валидатор принимает настройки `minLength`, `requireDigit` и `requireUppercase`.
Композиция `compose` применяет функции справа налево, как принято в функциональной композиции.
