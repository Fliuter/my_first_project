# Ответы на вопросы для самоконтроля — ПР8

1. **Какие инструменты графического редактора наиболее полезны для извлечения информации о размерах, цветах и шрифтах?**  
   Полезны панель свойств, инструменты измерения расстояний, просмотр параметров текста, пипетка и инспектор элементов. В Figma также можно выделить объект и посмотреть его ширину, высоту, отступы, цвет и параметры шрифта.

2. **Как правильно организовать структуру CSS-переменных на основе данных из макета?**  
   Основные повторяющиеся значения нужно вынести в `:root`: цвета, шрифты, размеры контейнера, радиусы, интервалы и длительность анимаций. Это упрощает изменение общего оформления сайта.

3. **Какие метрики из макета наиболее критичны для точной верстки (размеры, отступы, шрифты)?**  
   Важны ширина и высота блоков, положение элементов, внутренние и внешние отступы, размеры шрифтов, межстрочные интервалы, начертание и цвета. Они сильнее всего влияют на визуальное сходство.

4. **Как определить систему сетки, используемую в макете и перенести ее в CSS Grid или Flexbox?**  
   Нужно посмотреть количество колонок, ширину контейнера, расстояния между колонками и выравнивание элементов. Для двумерной сетки удобно применять CSS Grid, а для расположения элементов в одной строке или колонке — Flexbox.

5. **Какие сложности возникают при переносе типографики из графического макета в веб-страницу?**  
   Шрифт может отсутствовать в веб-доступе, а его начертание и метрики могут отличаться. Из-за этого меняются переносы строк, ширина текста и высота блоков. Нужно подобрать доступный аналог и проверить результат в браузере.

6. **Как обрабатывать адаптивность, когда в макете представлен только десктопный вариант?**  
   Следует определить, какие блоки можно перестроить на узком экране, уменьшить боковые отступы, изменить размеры текста и при необходимости расположить карточки вертикально. Результат проверяется на нескольких ширинах экрана.

7. **Какие инструменты браузера помогают сравнивать сверстанную страницу с оригинальным макетом?**  
   Инструменты разработчика позволяют проверять размеры, отступы, шрифты, цвета и CSS-свойства. Также полезны режим адаптивного просмотра и наложение скриншота макета поверх страницы для визуального сравнения.

8. **Как правильно экспортировать изображения из графического редактора для веб-использования?**  
   Нужно выбрать подходящий формат: JPEG или WebP для фотографий, PNG для изображений с прозрачностью, SVG для векторной графики. Следует подобрать достаточное разрешение, сжать файл и дать ему понятное имя.

9. **Что делать, если в макете используются шрифты, которых нет в веб-доступе?**  
   Сначала нужно проверить, можно ли получить и законно использовать веб-версию шрифта. Если нет, выбирают максимально похожий доступный шрифт и корректируют размер, межстрочный интервал и насыщенность.

10. **Какие методологии помогают поддерживать соответствие между макетом и кодом при дальнейших изменениях?**  
    Помогают единые дизайн-токены и CSS-переменные, компонентный подход, понятная структура классов, повторное использование компонентов и регулярная проверка страницы по макету после изменений.
