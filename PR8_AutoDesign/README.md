# Практическая работа №8 — DRIVE

Откройте `index.html` в браузере (двойной щелчок по файлу).

## Состав проекта
- `index.html` — страница сайта.
- `styles/variables.css` — CSS-переменные.
- `styles/main.css` — основные стили и адаптивность.
- `answers.md` — ответы на 10 вопросов.
- `report.md` — отчёт о соответствии макету.
- `images/` — папка для изображений.

## Важно перед сдачей
В `report.md` добавьте реальную ссылку на ваш макет Figma. Внешние фоновые фотографии загружаются из интернета, поэтому для их отображения требуется подключение к сети.
