# Отчёт о соответствии макету — ПР8

## 1. Описание макета
Для практической работы подготовлен учебный макет главной страницы автомобильного проекта DRIVE. Страница включает шапку с логотипом и навигацией, главный экран с заголовком и кнопкой, информационный блок, три карточки преимуществ и футер с контактами.

**Ссылка на макет Figma:**  
`Вставить ссылку на собственный файл Figma после его создания.`

> Важно: проект содержит готовую веб-версию и описание макета. Файл Figma не создаётся автоматически этим проектом — ссылку необходимо добавить после создания/сохранения макета в аккаунте Figma.

## 2. Структура проекта
- `index.html` — семантическая HTML-разметка страницы.
- `styles/variables.css` — общие CSS-переменные: цвета, шрифт, ширина контейнера, интервалы.
- `styles/main.css` — оформление блоков, сетки, состояния элементов и адаптивные правила.
- `images/` — папка для локальных изображений. В демонстрации фоновые фотографии загружаются по внешним ссылкам.

## 3. Основные параметры дизайна
| Элемент | Размеры и расположение | Цвета и типографика | Особенности |
|---|---|---|---|
| Header | Высота 82 px, контейнер до 1180 px | Тёмный фон `#101820`, Manrope | Логотип, навигация, кнопка |
| Hero | Минимальная высота 650 px | Тёмный фон, белый текст, акцент `#E94F2E` | Фоновая фотография, заголовок и CTA |
| Intro | Контейнер до 1180 px | Светлый фон `#F3F4F2` | Двухколоночная компоновка |
| Преимущества | 3 карточки в ряд | Белые карточки и тёмная акцентная карточка | CSS Grid, одинаковые интервалы |
| Callout | Широкий блок | Тёмный фон, белый и акцентный текст | Призыв к действию |
| Footer | Нижняя часть страницы | `#101820`, светлый текст | Контакты и ссылка наверх |

## 4. Цветовая палитра
- Основной тёмный: `#101820`.
- Дополнительный тёмный: `#1B2933`.
- Акцентный: `#E94F2E`.
- Светлый фон: `#F3F4F2`.
- Белый: `#FFFFFF`.
- Основной текст: `#18232B`.
- Вторичный текст: `#89939A`.

## 5. Типографика и сетка
В качестве основного шрифта используется Manrope с резервным Arial. Максимальная ширина контента — 1180 px. Карточки преимуществ расположены в три колонки с помощью CSS Grid. Для шапки и нижнего блока применён Flexbox.

## 6. Адаптивность
При ширине экрана до 760 px карточки перестраиваются в одну колонку, блоки intro становятся одноколоночными, навигация скрывается в компактное меню, а размеры и отступы уменьшаются. Для проверки можно изменить ширину окна браузера или включить режим устройства в инструментах разработчика.

## 7. Проверка соответствия
Проверены структура страницы, расположение основных секций, единая цветовая палитра, типографика, сетка карточек и адаптивное поведение. Для окончательного сравнения с Figma необходимо открыть собственный макет рядом со страницей в браузере и при необходимости скорректировать значения размеров и отступов.

## 8. Вывод
В ходе практической работы подготовлена адаптивная страница по учебному дизайн-макету. Использованы семантические HTML-элементы, CSS-переменные, Grid, Flexbox и медиазапросы. Структура проекта разделена на HTML и CSS-файлы.
