# ПР №14 — Работа с Fetch API

## Состав проекта
- `index.html` — интерфейс с кнопками для всех демонстраций.
- `styles.css` — оформление.
- `fetch-tasks.js` — реализация GET/POST/PUT/PATCH/DELETE, заголовков, параметров, обработки ошибок, отмены, параллельных запросов, FormData, Blob, поиска и кэша.
- `fetch-tests.js` — базовые автоматические проверки окружения и наличия функций.
- `answers.md` — ответы на 10 вопросов.

## Запуск
Откройте `index.html` в современном браузере и нажимайте кнопки. Для запросов нужен интернет: используется публичный JSONPlaceholder API. Если браузер ограничивает запросы из `file://`, откройте папку через локальный сервер (например, расширение Live Server в VS Code).

## Важно
JSONPlaceholder — демонстрационный API: POST/PUT/PATCH/DELETE возвращают имитацию результата, но не сохраняют изменения на постоянной основе. Авторизация показана учебным примером, реальную проверку токена этот сервис не выполняет. Fetch API не предоставляет стандартного события прогресса отправки файла; для такого прогресса используется XMLHttpRequest.
