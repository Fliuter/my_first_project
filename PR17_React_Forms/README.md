# ПР №17 — React: работа с формами

## Цель
Освоить создание и управление формами в React: управляемые и неуправляемые компоненты, обработку событий и валидацию данных.

## Содержание
- `src/components/UserRegistrationForm.js` — управляемая форма регистрации.
- `src/components/UserRegistrationFormWithValidation.js` — регистрация с проверкой обязательных полей, формата email, длины пароля и совпадения паролей.
- `src/components/ContactFormUncontrolled.js` — форма обратной связи с `useRef`.
- `src/App.js` — объединяет три формы на одной странице.
- `answers.md` — ответы на 7 вопросов для самоконтроля.

## Запуск
1. Установите Node.js.
2. Откройте терминал в папке `PR17_React_Forms`.
3. Выполните `npm install`.
4. Выполните `npm start`.
5. Откройте адрес, который покажет React в терминале (обычно `http://localhost:3000`).

Формы демонстрационные: данные обрабатываются в браузере и не отправляются на сервер.
