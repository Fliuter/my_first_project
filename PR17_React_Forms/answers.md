# Ответы на вопросы для самоконтроля — ПР №17

**1. В чем разница между управляемыми и неуправляемыми компонентами в формах React?**

В управляемом компоненте значение поля хранится в состоянии React (`useState`) и изменяется через обработчик `onChange`. В неуправляемом компоненте значение хранится в DOM, а для получения данных обычно используется ссылка `useRef`.

**2. Когда следует использовать управляемые компоненты, а когда — неуправляемые?**

Управляемые компоненты удобны, когда нужно проверять ввод, динамически менять интерфейс и контролировать каждое изменение. Неуправляемые подходят для простых форм, когда значение нужно получить в момент отправки, а постоянное управление полем не требуется.

**3. Какие методы используются для обработки событий в формах React?**

Чаще всего применяются обработчики `onChange` для изменения полей, `onSubmit` для отправки формы, а также `onBlur` и `onFocus` для обработки потери и получения фокуса.

**4. Как обрабатывать несколько полей ввода с одним обработчиком?**

Каждому полю задают атрибут `name`, а в общем обработчике получают `name` и `value` из `event.target`. Затем обновляют нужное свойство объекта состояния, например: `setForm(prev => ({ ...prev, [name]: value }))`.

**5. Какие подходы к валидации форм в React вы знаете?**

Можно проверять данные вручную в обработчике отправки или при изменении поля. Также применяются встроенные HTML-атрибуты (`required`, `type="email"`, `minLength`) и библиотеки для форм и проверки данных.

**6. Как предотвратить стандартное поведение формы (перезагрузку страницы)?**

В обработчике `onSubmit` нужно вызвать `event.preventDefault()`. Это отменяет стандартную отправку формы и перезагрузку страницы.

**7. Что такое «поднятие состояния» (lifting state up) в контексте форм?**

Это перенос состояния из дочернего компонента в общий родительский компонент, чтобы несколько компонентов могли использовать и изменять одни и те же данные через props и переданные обработчики.
