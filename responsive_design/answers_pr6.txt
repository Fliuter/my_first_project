Ответы на вопросы для самоконтроля — ПР №6

1. Что такое Viewport meta tag и почему он важен для адаптивного дизайна?
Viewport meta tag — это метатег, который задаёт браузеру ширину области просмотра страницы. Запись width=device-width устанавливает ширину равной ширине экрана устройства, а initial-scale=1.0 задаёт начальный масштаб. Без него мобильный браузер может отображать страницу как уменьшенную десктопную версию.

2. Какие основные подходы к созданию адаптивных макетов вы использовали в работе (Fluid, Adaptive, Responsive)?
В работе использован Responsive-подход: макет плавно перестраивается с помощью гибких размеров, CSS Grid и медиазапросов. Также применены элементы Fluid-подхода — например, контейнер с шириной в процентах. Adaptive-подход предполагает отдельные варианты макета для заданных диапазонов экранов.

3. Как работает Mobile First подход и в чем его преимущества перед Desktop First?
Mobile First означает, что сначала создаются стили для маленьких экранов, а затем с помощью min-width добавляются возможности для больших экранов. Такой подход помогает сосредоточиться на главном содержимом, упрощает мобильную версию и позволяет постепенно расширять макет.

4. Какие единицы измерения наиболее предпочтительны для адаптивной верстки и почему (%, rem, em, vw/vh)?
Проценты подходят для гибкой ширины элементов и контейнеров. rem зависит от размера шрифта корневого элемента и удобен для размеров текста и отступов. em зависит от размера шрифта текущего элемента. vw и vh задают размеры относительно ширины и высоты окна браузера. Выбор зависит от задачи; фиксированные пиксели лучше не использовать для всех размеров подряд.

5. Как функция clamp() помогает создавать адаптивную типографику?
clamp() задаёт минимальное, предпочтительное и максимальное значение. Например, font-size: clamp(2rem, 5vw, 3.6rem) позволяет заголовку плавно увеличиваться вместе с экраном, но не становиться слишком маленьким или слишком большим.

6. Какие основные брейкпоинты вы использовали и как определили эти значения?
В работе использованы диапазоны до 480px для маленьких телефонов, до 767px для мобильных устройств, 768–1024px для планшетов и более 1024px для больших экранов. Значения выбраны как распространённые ориентиры и проверяются по тому, где содержимое начинает выглядеть тесно.

7. Как медиа-запросы @media помогают создавать адаптивные стили? Приведите пример синтаксиса.
Медиа-запросы позволяют применять CSS-правила только при определённых характеристиках экрана. Пример: @media (max-width: 767px) { .card-grid { grid-template-columns: 1fr; } } — на узком экране карточки располагаются в одну колонку.

8. В чем разница между max-width и min-width в медиа-запросах и когда использовать каждый?
max-width применяет стили, когда ширина окна не превышает указанное значение. Его удобно использовать при подходе Desktop First. min-width применяет стили при ширине не меньше заданной величины и часто используется в Mobile First.

9. Как сделать изображения адаптивными и какие CSS-свойства для этого используются?
Обычно изображениям задают max-width: 100% и height: auto, чтобы они не выходили за границы контейнера и сохраняли пропорции. В карточках также можно использовать width: 100%, object-fit: cover и aspect-ratio для одинакового размера изображений.

10. Какие инструменты браузера помогают тестировать и отлаживать адаптивный дизайн?
В инструментах разработчика браузера используется режим адаптивного дизайна или Device Toolbar. Он позволяет менять ширину и высоту экрана, выбирать модели устройств, проверять брейкпоинты, смотреть CSS-правила и находить ошибки вёрстки. Также полезно проверять страницу в обычном окне браузера и на реальных устройствах.
