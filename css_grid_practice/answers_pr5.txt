Ответы на вопросы для самоконтроля
Практическая работа №5 «Создание сетки на CSS Grid»

1. Какое основное свойство включает CSS Grid и чем принципиально отличается от Flexbox?
Для включения Grid используется display: grid. CSS Grid предназначен для двумерной раскладки: одновременно по строкам и столбцам. Flexbox в основном управляет расположением элементов в одном направлении — в строке или колонке.

2. В чем разница между grid-template-columns и grid-auto-columns? Когда следует использовать каждое?
grid-template-columns задаёт размеры и количество столбцов основной сетки. grid-auto-columns задаёт размер столбцов, которые браузер создаёт автоматически, если элемент выходит за пределы явно заданной сетки.

3. Что делают функции repeat(), minmax() и auto-fit в определении grid-шаблона? Приведите примеры.
repeat() повторяет заданный шаблон столбцов или строк, например repeat(3, 1fr). minmax() задаёт минимальный и максимальный размер, например minmax(180px, 1fr). auto-fit автоматически подбирает количество колонок и растягивает их, чтобы заполнить доступное пространство: repeat(auto-fit, minmax(180px, 1fr)).

4. Как работают именованные grid-области и какие преимущества они дают при создании макетов?
Именованные области задаются через grid-template-areas, а затем назначаются элементам свойством grid-area. Это делает CSS-сетку понятнее: например, можно отдельно указать header, nav, main, sidebar и footer.

5. Объясните систему нумерации grid-линий и как с помощью grid-column и grid-row размещать элементы.
Линии сетки нумеруются начиная с единицы слева направо для колонок и сверху вниз для строк. Свойство grid-column задаёт начальную и конечную вертикальные линии, а grid-row — горизонтальные. Например, grid-column: 1 / 3 занимает пространство от первой до третьей линии колонок.

6. Что такое grid-gap (или gap) и чем он лучше margins для создания промежутков в сетке?
gap задаёт расстояние между строками и столбцами Grid. В отличие от margins, он управляет промежутками именно между элементами сетки и не создаёт лишние внешние отступы по краям контейнера.

7. Как свойства justify-items и align-items влияют на выравнивание grid-элементов?
justify-items выравнивает содержимое ячеек по горизонтальной оси, а align-items — по вертикальной оси. Например, можно задать center, чтобы расположить элементы по центру ячеек.

8. В чем разница между auto-fill и auto-fit при создании адаптивных сеток?
Оба значения автоматически рассчитывают количество колонок. auto-fill сохраняет свободные пустые ячейки, а auto-fit схлопывает пустые колонки и позволяет оставшимся элементам занять больше места.

9. Как создать сложные макеты с помощью grid-template-areas и какие правила именования областей существуют?
Нужно записать схему макета строками в grid-template-areas, используя одинаковые имена для ячеек одной области. Каждая строка должна содержать одинаковое количество колонок, а область должна образовывать прямоугольник. Для пустых ячеек используется точка.

10. Какие преимущества дает CSS Grid перед другими методами верстки для создания сложных двумерных макетов?
Grid позволяет точно задавать строки, столбцы и области, менять расположение блоков на разных экранах и создавать адаптивные макеты без сложных обходных решений. Он удобен для структуры всей страницы и вложенных сеток.
