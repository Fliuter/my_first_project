Что такое CSS Grid?

CSS Grid — технология CSS для создания двумерных макетов. Она позволяет размещать элементы одновременно по строкам и столбцам.

Дополнительно

Grid помогает создавать адаптивные сетки, карточки и сложные структуры страниц.

Основные свойства: display: grid, grid-template-columns, gap, grid-area.
