Ответы на вопросы для самоконтроля
Практическая работа №4 «Построение layout с помощью Flexbox»

1. Какое основное свойство CSS включает Flexbox и что происходит с дочерними элементами после его применения?
Flexbox включается свойством display: flex. Элемент становится flex-контейнером, а его непосредственные дочерние элементы — flex-элементами. Ими можно управлять с помощью свойств выравнивания, направления и распределения свободного места.

2. В чем разница между justify-content и align-items? Приведите примеры использования каждого.
justify-content распределяет элементы вдоль основной оси. Например, justify-content: space-between размещает элементы с равными промежутками между ними. align-items выравнивает элементы по поперечной оси. Например, align-items: center располагает их по центру поперечной оси.

3. Что делает свойство flex-direction и какие значения может принимать? Как оно влияет на основную ось?
flex-direction задаёт направление расположения flex-элементов. Основные значения: row, row-reverse, column и column-reverse. При row основная ось горизонтальная, а при column — вертикальная. Значения с reverse меняют порядок элементов на обратный.

4. Объясните значение трех свойств в сокращенной записи flex: 1. Что означают flex-grow, flex-shrink и flex-basis?
Свойство flex является сокращённой записью flex-grow, flex-shrink и flex-basis. flex-grow определяет, насколько элемент может увеличиваться при наличии свободного места. flex-shrink задаёт, насколько он может уменьшаться при нехватке места. flex-basis задаёт исходный размер элемента до распределения свободного пространства. Запись flex: 1 обычно позволяет элементу занимать доступное пространство и сжиматься при необходимости.

5. Как работает свойство flex-wrap и в каких случаях его следует использовать?
flex-wrap определяет, могут ли элементы переноситься на следующую строку. Значение nowrap запрещает перенос, wrap разрешает его, а wrap-reverse меняет направление переноса. Свойство полезно, когда карточки или другие элементы не помещаются в одну строку, особенно на узких экранах.

6. Чем отличается align-content от align-items и когда применяется каждое из этих свойств?
align-items выравнивает элементы внутри одной flex-линии по поперечной оси. align-content распределяет сами flex-линии, когда их несколько и есть свободное место по поперечной оси. Поэтому align-content обычно имеет смысл при включённом переносе элементов.

7. Как свойство order влияет на отображение элементов и в каких практических ситуациях оно может быть полезно?
order задаёт порядок отображения flex-элементов. Элементы с меньшим значением располагаются раньше. Свойство полезно, например, чтобы изменить визуальный порядок карточек или блоков на разных размерах экрана без изменения HTML-разметки.

8. Что такое «осевая линия» (main axis) и поперечная ось (cross axis) в Flexbox и как они связаны с flex-direction?
Основная ось (main axis) — направление, вдоль которого располагаются flex-элементы. Поперечная ось (cross axis) перпендикулярна основной. При flex-direction: row основная ось горизонтальная, а при flex-direction: column — вертикальная. Поэтому при смене направления меняются и оси.

9. Как создать адаптивный макет с помощью Flexbox без использования медиа-запросов? Приведите пример.
Можно использовать flex-wrap: wrap и гибкие размеры элементов, например flex: 1 1 250px. Карточки будут занимать доступное место и переноситься на новую строку, когда им не хватает ширины. Такой способ подходит для простых адаптивных сеток.

10. Какие преимущества дает использование gap вместо margins для создания промежутков между flex-элементами?
gap задаёт расстояние между элементами контейнера, не добавляя внешние отступы по краям ряда. Это упрощает настройку промежутков, уменьшает необходимость убирать лишние отступы у крайних элементов и делает CSS понятнее.
