# ПР №15 — React: создание компонентов

## Требования
- Node.js (LTS) и npm.
- Браузер и редактор кода.

## Запуск проекта
1. Откройте терминал в папке проекта.
2. Выполните `npm install`.
3. Выполните `npm run dev`.
4. Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Проверка
- Пройдите по всем разделам страницы.
- Проверьте счётчики, форму входа, выбор цвета, список задач и поиск.
- Запустите секундомер, измените размер окна.
- Проверьте загрузку данных (нужен интернет).
- Измените тему и имя — они сохраняются в localStorage.
- Нажмите «Запустить тесты компонентов».

## Структура
```text
src/
  components/
    basic/BasicComponents.js
    basic/BasicComponents.css
    stateful/StatefulComponents.js
    stateful/StatefulComponents.css
    lifecycle/LifecycleComponents.js
    lifecycle/LifecycleComponents.css
    hooks/HooksComponents.js
    hooks/HooksComponents.css
    ComponentTests.js
  App.js
  App.css
  index.js
answers.md
```

В проекте используется Vite для запуска React-приложения. Это современная замена устаревшему шаблону Create React App; структура компонентов соответствует заданию.
