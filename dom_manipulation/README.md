# Практическая работа №11

**Тема:** JavaScript: манипуляции DOM-деревом.

## Состав проекта
- `index.html` — страница с демонстрацией заданий.
- `styles.css` — оформление страницы.
- `dom-tasks.js` — реализация функций создания элементов, навигации по DOM, работы с классами, событиями, списками и формами.
- `dom-tests.js` — автоматические проверки основных функций.
- `answers.md` — ответы на 10 вопросов для самоконтроля.

## Запуск
Откройте `index.html` в браузере. Все основные функции доступны через кнопки и поля страницы.

## Запуск тестов
Откройте инструменты разработчика браузера (F12), вкладку Console, вставьте:

```javascript
const s = document.createElement('script');
s.src = 'dom-tests.js';
document.body.append(s);
```

Результаты тестов появятся в консоли в виде таблицы.

## Примечание
Проект работает локально в браузере и не требует сервера или установки дополнительных библиотек.
