# Ответы на вопросы для самоконтроля — ПР №11

1. **В чем разница между `innerHTML` и `textContent` и когда следует использовать каждый метод?**  
   `innerHTML` получает или изменяет HTML-разметку внутри элемента. Он подходит, когда действительно нужно вставить HTML, но нельзя без проверки вставлять в него данные пользователя: это может привести к XSS-уязвимости. `textContent` работает как обычный текст и не интерпретирует HTML-теги. Для вывода пользовательского текста безопаснее использовать `textContent`.

2. **Как работает делегирование событий и какие преимущества оно дает при работе с динамическими элементами?**  
   Обработчик устанавливается на общего родителя, а событие от дочернего элемента всплывает до него. В обработчике проверяется `event.target` или используется `closest()`. Это позволяет обрабатывать в том числе элементы, которые были добавлены позже, и не назначать отдельный обработчик каждой кнопке.

3. **Какие методы используются для поиска элементов в DOM и в чем разница между `getElementById`, `querySelector` и `querySelectorAll`?**  
   `getElementById()` ищет элемент по уникальному идентификатору. `querySelector()` возвращает первый элемент, подходящий CSS-селектору. `querySelectorAll()` возвращает статическую коллекцию всех подходящих элементов.

4. **Как предотвратить стандартное поведение элемента при обработке событий и когда это необходимо?**  
   Для этого вызывают `event.preventDefault()`. Например, при обработке отправки формы это предотвращает перезагрузку страницы, чтобы можно было проверить данные и показать результат средствами JavaScript.

5. **В чем разница между `classList.add()` и `className` для работы с CSS классами?**  
   `classList.add()` добавляет один или несколько классов, не удаляя остальные. `className` задаёт или возвращает всю строку атрибута `class`; при присваивании можно случайно перезаписать уже имеющиеся классы.

6. **Как создать новый элемент и добавить его в DOM несколькими способами? Какой способ наиболее эффективен?**  
   Элемент можно создать через `document.createElement()`, затем добавить с помощью `append()`, `appendChild()`, `prepend()` или `before()`. Также существует вставка HTML через `insertAdjacentHTML()`. Для создания элементов и безопасного добавления текста удобен `createElement()` вместе с `append()`. При добавлении большого количества узлов можно сначала собрать их в `DocumentFragment`, а затем вставить одной операцией.

7. **Что такое всплытие событий и как работает метод `stopPropagation()`?**  
   Всплытие — это распространение события от целевого элемента вверх по его родителям. `stopPropagation()` прекращает дальнейшее распространение события по DOM-дереву. Его используют, когда событие не должно обрабатываться родительскими элементами.

8. **Как получить данные из формы и в чем разница между методами сбора form data?**  
   Значения можно получить напрямую через свойства полей, например `input.value`, или собрать с помощью `new FormData(form)`. `FormData` собирает поля формы по атрибуту `name` и удобен для отправки данных. Для преобразования в обычный объект можно использовать `Object.fromEntries(new FormData(form).entries())`.

9. **Какие события используются для обработки ввода данных и в чем разница между `input`, `change` и `keyup`?**  
   `input` срабатывает при каждом изменении значения поля. `change` срабатывает, когда изменение подтверждено, обычно после потери фокуса или выбора значения. `keyup` срабатывает при отпускании клавиши и не всегда отражает изменения, сделанные вставкой мышью или автозаполнением.

10. **Как оптимизировать производительность при частых манипуляциях с DOM?**  
    Следует объединять несколько изменений DOM, использовать `DocumentFragment`, не выполнять многократные чтения и записи layout-свойств вперемешку, применять делегирование событий и обновлять только необходимые части страницы. Для часто вызываемых обработчиков можно использовать debounce или throttle.
