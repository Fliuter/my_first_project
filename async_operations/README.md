# Практическая работа №13
## JavaScript: асинхронные операции

### Состав проекта
- `index.html` — интерфейс для запуска демонстраций.
- `styles.css` — оформление страницы.
- `async-tasks.js` — реализация промисов, async/await, API, таймеров, обработки ошибок, параллельных операций и кэширования.
- `async-tests.js` — автоматические проверки основных функций.
- `answers.md` — ответы на вопросы для самоконтроля.

### Запуск
Откройте `index.html` в браузере. Для работы с JSONPlaceholder API требуется подключение к интернету. Тесты запускаются кнопкой «Запустить тесты».

### Примечание
JSONPlaceholder — тестовый сервис. POST-запрос имитирует создание записи и не сохраняет её в настоящей базе данных.
