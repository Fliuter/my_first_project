Основы CSS

CSS — это язык стилей для веб-страниц.

Он позволяет управлять внешним видом элементов: цветом, размером текста, отступами и расположением блоков.

Каскад и наследование

Каскад определяет, какое CSS-правило будет применено к элементу.

Наследование позволяет некоторым свойствам переходить от родителя к дочерним элементам.
