Ответы на вопросы для самоконтроля — ПР №3

1. В чем разница между селектором по классу и по ID с точки зрения специфичности и возможности повторного использования?

Селектор класса записывается через точку, например .card. Его можно использовать для нескольких элементов. Селектор ID записывается через решётку, например #site-title, и предназначен для уникального элемента. Специфичность ID выше, чем у класса.

2. Как работает каскад в CSS и в каком порядке применяются стили при конфликте правил?

Браузер учитывает источник и важность правила, специфичность селектора и порядок расположения правил. Если правила имеют одинаковую важность и специфичность, применяется то, которое записано позже.

3. Рассчитайте специфичность для селекторов:
- ul li.important — (0, 1, 2): один класс и два селектора по тегу.
- #site-title — (1, 0, 0): один ID.
- .content > .featured-post — (0, 2, 0): два класса. Знак > на специфичность не влияет.

4. Какие свойства в CSS наследуются по умолчанию, а какие нет? Приведите по 3 примера каждого типа.

Обычно наследуются color, font-family и line-height. Обычно не наследуются margin, padding и border. При необходимости наследование можно задать явно с помощью значения inherit.

5. Как работает селектор > (дочерний селектор) и чем он отличается от селектора потомков (через пробел)?

Селектор > выбирает только непосредственных дочерних элементов. Селектор с пробелом выбирает все подходящие элементы на любом уровне вложенности. Например, .content > p выберет только абзацы прямо внутри .content, а .content p — все абзацы внутри него.

6. Для чего используются псевдоклассы :hover и :nth-child()? В каких практических задачах они могут пригодиться?

:hover применяет стиль при наведении курсора. Его используют для подсветки ссылок, кнопок и пунктов меню. :nth-child() выбирает элемент по его порядковому номеру среди соседних элементов, например для выделения каждой нечётной строки таблицы.

7. Что делает правило !important и почему его следует использовать с осторожностью?

!important повышает приоритет объявления CSS и позволяет ему переопределять обычные правила. Его следует использовать редко, потому что он усложняет понимание каскада и дальнейшее изменение стилей.

8. Как псевдоэлементы ::before и ::after расширяют возможности CSS и какой контент они могут содержать?

Они добавляют оформляемое содержимое перед элементом или после него без изменения HTML. Для вывода используется свойство content. Можно добавлять текст, символы и декоративные элементы.

9. В каком порядке браузер применяет CSS-правила при одинаковой специфичности селекторов?

Если правила имеют одинаковую важность и специфичность, браузер применяет правило, которое находится ниже в CSS-файле, то есть объявлено позже.

10. Как инструменты разработчика в браузере помогают анализировать и отлаживать CSS-код?

В инструментах разработчика можно выбрать HTML-элемент, посмотреть применённые CSS-правила, увидеть перечёркнутые свойства, проверить специфичность, временно изменить значения и найти ошибки в стилях.
