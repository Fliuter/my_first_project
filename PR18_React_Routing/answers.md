# Ответы на вопросы для самоконтроля — ПР №18

**1. В чем разница между Link и NavLink в React Router?**  
`Link` создаёт обычную ссылку для перехода между маршрутами без перезагрузки страницы. `NavLink` делает то же самое, но дополнительно определяет, активен ли текущий маршрут. Поэтому `NavLink` удобно использовать в меню навигации и применять активному пункту отдельный стиль.

**2. Как получить параметры из URL в компоненте?**  
Для этого используется хук `useParams` из `react-router-dom`. Например, для маршрута `<Route path="/products/:id" element={<ProductDetail />} />` вызов `const { id } = useParams()` вернёт значение параметра `id` из адреса.

**3. Что такое программная навигация и как ее реализовать?**  
Программная навигация — это переход на другой маршрут из JavaScript-кода, например после отправки формы. В React Router для этого используется хук `useNavigate`: `const navigate = useNavigate();`, затем `navigate('/contact/success')`.

**4. Как передать данные между маршрутами?**  
Данные можно передать через состояние навигации: `navigate('/contact/success', { state: { name: 'Иван' } })`. На целевой странице их можно получить через `const location = useLocation();` и `location.state`. Для данных, которые должны быть частью адреса, используют параметры URL.

**5. Что делает компонент Routes?**  
`Routes` перебирает объявленные внутри него маршруты `Route` и отображает элемент того маршрута, который соответствует текущему URL. Это основной контейнер для описания маршрутизации в React Router 6.

**6. Как создать защищённый маршрут?**  
Создают отдельный компонент-обёртку, который проверяет авторизацию пользователя. Если пользователь авторизован, обёртка возвращает `Outlet` или переданный компонент. Если нет — выполняет перенаправление через `Navigate` на страницу входа. Проверка должна опираться на реальное состояние авторизации, а не только на наличие элемента интерфейса.

**7. В чем разница между useNavigate и redirect?**  
`useNavigate` — хук для программного перехода из компонента, например по нажатию кнопки или после действия пользователя. `redirect` — функция React Router, обычно применяемая в `loader` или `action` маршрута для перенаправления во время выполнения маршрутизатора, до отображения целевого элемента.
