# ПР №18 — React: маршрутизация

Учебное SPA-приложение на React с использованием React Router v6.

## Реализовано
- `BrowserRouter`, `Routes`, `Route` и меню на `NavLink`.
- Главная, информационная страница и маршрут 404.
- Каталог товаров с фильтрацией по категориям.
- Динамический маршрут `/products/:id` и получение ID через `useParams`.
- Программная навигация через `useNavigate`.
- Передача данных через `navigate(..., { state })` и получение через `useLocation`.
- Форма обратной связи с проверкой полей и страница подтверждения.
- Ответы на 7 вопросов в `answers.md`.

## Запуск
1. Установить Node.js LTS.
2. Открыть терминал в папке `PR18_React_Routing`.
3. Выполнить `npm install`.
4. Выполнить `npm start`.
5. Приложение откроется по адресу `http://localhost:3000`.

Форма демонстрационная: данные передаются между маршрутами в состоянии навигации, но не отправляются на сервер и не сохраняются в базе данных.
