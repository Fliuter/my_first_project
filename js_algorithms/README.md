# Практическая работа №9 — JavaScript: базовые алгоритмы

## Состав проекта
- `index.html` — страница для запуска тестов.
- `algorithms.js` — реализация алгоритмов.
- `tests.js` — автоматические проверки.
- `style.css` — оформление страницы.
- `answers_pr9.txt` — ответы на вопросы для самоконтроля.

## Запуск
Откройте `index.html` в браузере и нажмите кнопку «Запустить тесты».
Все файлы проекта должны находиться в одной папке.

## Примечание
Функции factorial возвращают `null` для отрицательных или нецелых значений. Функция fibonacci возвращает пустой массив для некорректного значения n.
